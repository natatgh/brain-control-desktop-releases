# Second Brain Desktop — releases

Este repositório público contém somente instaladores e arquivos de atualização do aplicativo desktop Second Brain. O código-fonte permanece no repositório privado brain-control.

Quando houver uma versão publicada, baixe o instalador na página de [Releases](https://github.com/natatgh/brain-control-desktop-releases/releases). O aplicativo também verifica atualizações automaticamente.
